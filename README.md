## English

### GitHub About

Smart Windscribe auto-connect and network scanner for filtered networks. Finds the best working server, protocol, and port while learning from your network conditions. (FA/EN)

### Overview

**WindScout** is a smart Windows desktop application designed to find the best working Windscribe connection for your network.

It analyzes network restrictions, tests available servers, protocols, and ports, then automatically selects the most reliable connection. With every scan, it learns more about your network and improves future connection recommendations.

### Features

- **Smart Connect** – Connect with one click. Analyzes network restrictions, selects the best server, protocol, and port based on previous results from the same network, and monitors tunnel health with automatic reconnection.
- **Real Connection Verification** – A connection is considered successful only when a real HTTPS request succeeds and the external IP address and country are verified to have changed.
- **Advanced Scanner** – Includes Smart (Discover → Expand), City-by-City, and Chaos scanning modes, with continent, city, and location filters, customizable port selection, protocol priorities, and scan profiles.
- **Speed Test & Network Diagnostics** – Measures download speed, upload speed, and ping; checks UDP availability, SNI/DPI filtering, DNS interference, and accessible TCP ports; then provides server recommendations based on actual test results.
- **Results & Best Servers** – Searchable results table with CSV export. Scan history is stored separately for each network, making it easy to identify working protocols, ports, and the fastest servers.
- **Favorites & IP Hiding** – Save favorite servers and hide your IP address in screenshots and recordings.
- **Bilingual Interface** – Fully supports Persian and English, with a convenient FA/EN toggle in the top bar.
- **Portable** – Comes with its own bundled Python runtime. No separate Python installation or setup required.

### Requirements

- Windows 10 or Windows 11
- Windscribe desktop application installed and signed in

### Usage

1. Download and extract the entire package. Do not run the application directly from inside the ZIP file.
2. Launch `WindScout.exe`. Make sure the `runtime` and `app` folders remain alongside the executable.
3. If Windows SmartScreen displays a warning, select **More info → Run anyway** only if you trust the application and its source.
